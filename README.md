# BlockWorld Engine

Минимальный 3D-воксельный мир на Python и OpenGL. Приложение отображает травяную
местность с холмами размером 100 × 100 блоков в мире высотой 100 блоков и
позволяет исследовать её от первого лица.

## Требования

- Windows и Python 3.13 или новее;
- видеодрайвер с поддержкой OpenGL 3.3;
- графическое окружение, в котором можно открыть окно.

Если Python 3.13 не установлен, используйте установленную совместимую версию
Python. Например, в текущем окружении проекта используется Python 3.14.

## Установка и запуск в Windows PowerShell

Из корневой папки проекта выполните:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python main.py
```

Если PowerShell запрещает активацию виртуального окружения, разрешите её только
для текущего процесса и повторите команду активации:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
```

Чтобы запустить приложение без активации окружения, используйте:

```powershell
.\.venv\Scripts\python.exe main.py
```

## Управление

- `W`, `A`, `S`, `D` — движение;
- мышь — обзор;
- `Space` — прыжок;
- клавиши `1`–`9` или колесо мыши — выбрать ячейку панели;
- `F3` — показать или скрыть панель производительности;
- `F4` — показать или скрыть сетку границ чанков на поверхности мира;
- левая кнопка мыши — сломать блок под прицелом;
- правая кнопка мыши — поставить выбранный блок рядом с блоком под прицелом;
- клавиши `1`–`9` или колесо мыши — выбрать ячейку панели;
- `Esc` — открыть меню паузы с размытым игровым фоном и курсором на кнопке
  «Продолжить»; кнопки меню расположены сверху вниз: продолжить, настройки, выход.
  В настройках `Esc` возвращает в меню паузы.
- Кнопка «Выход из игры» в меню — закрыть приложение.
- В настройках можно выбрать фильтрацию текстур (низкая, средняя, высокая) и
  качество теней (выключено, низкое, высокое), а также цветокоррекцию
  (выключена, тёплая, холодная или кинематографичная) и включить/отключить
  атмосферные эффекты.

Прицел находится в центре экрана; расстояние взаимодействия с блоками — до 6 блоков.
Новый блок нельзя поставить внутри игрока. Курсор захватывается окном во время игры
и освобождается при открытии меню. Выразительные мягкие тени строятся PCF-фильтром
5 × 5 выборок по карте глубины и обновляются при изменении мира; низкое качество
использует карту 512 × 512, высокое — 1024 × 1024.
Качество текстур управляет фильтрацией mipmap-уровней.
Над миром отображается сферическое градиентное небо с движущимися облаками и
солнечным диском.
Направленный свет от солнца освещает грани блоков, а тени от объектов отбрасываются
в направлении, противоположном солнцу. При включённых атмосферных эффектах туман
плавно скрывает дальние блоки; облака и туман можно отключить в настройках.
Ячейки панели содержат траву, землю, камень, песок, листву, каменный кирпич,
булыжник, дерево и деревянные доски. Блоки можно ставить без ограничения
количества. Выбранная ячейка подсвечивается.
Мир генерируется с перепадами высот: поверхность покрыта травой, под ней лежат
три слоя земли, а более глубокие слои состоят из камня. Игрок появляется на
поверхности в центре мира.
В HUD также отображаются индикаторы здоровья и голода и шкала опыта.
Панель `F3` показывает FPS, время кадра, общее число кадров, загрузку CPU игрой
и системой, использование оперативной памяти игрой и системой, число блоков и
разрешение окна. Показатели CPU и памяти обновляются раз в секунду.
Сетка `F4` показывает границы чанков размером 8 × 8 блоков.

## Текстуры блоков

Текстуры загружаются из `assets/textures` при запуске. Поддерживаемые файлы:

- `Grass_Top.jfif` — верх травяного блока;
- `Grass_Side.jfif` — боковые грани травяного блока;
- `Dirt.jfif` — земля и нижняя грань травяного блока;
- `Stone.jfif` — камень;
- `Send.jfif` — песок;
- `Leaf.jfif` — листва;
- `Stone_Briks.jfif` — каменный кирпич;
- `Stone_Cobble.jfif` — булыжник;
- `Wood_Side.jfif` и `Wood_Top.jfif` — боковые грани и торцы дерева.
- `Wood_Board.jfif` — деревянные доски.

Текстуры объединяются в массив OpenGL и автоматически фильтруются mipmap-уровнями.
Если файл отсутствует или размеры изображений различаются, приложение сообщит
имя проблемной текстуры при инициализации.

## Структура

- `main.py` — точка входа;
- `engine/application.py` — инициализация GLFW/OpenGL, цикл приложения и очистка ресурсов;
- `engine/game/player.py` — камера от первого лица, движение, прыжок и столкновения;
- `engine/world/voxel_world.py` — массив блоков и объединённая геометрия видимых граней;
- `engine/graphics/renderer.py` — загрузка шейдеров и отрисовка меша мира;
- `engine/graphics/hud.py` — прицел, индикаторы состояния и выбираемая панель блоков;
- `assets/shaders/` — GLSL-шейдеры мира, неба, теней и размытия меню;
- `assets/textures/` — JPEG/JFIF-текстуры блоков;
- `tests/test_world_player.py` — тесты мира, игрока и панели быстрого доступа;
- `requirements.txt` — зависимости Python.
